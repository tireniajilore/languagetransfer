# Yoruba LT Lessons 1-4 Review Package

Status: draft scripts for native Yoruba review. Not native-certified.

Purpose: review the first four audio-only lessons for grammar, idiom, tone performance, register, and teaching naturalness.

## What To Review

Please review Lessons 1-4 in order:

1. Lesson 1: `Mo fẹ́ ...`, tone as held pitch, first sentence frame.
2. Lesson 2: same frame with more endings.
3. Lesson 3: informal singular `o`, "you".
4. Lesson 4: `ó`, "he/she/it", contrasted with `o`.

## Important Context

This is an audio-only course. The learner will not see Yoruba spelling, tone marks, or written explanations. The marks in the script are for the speaker/reviewer to pronounce the Yoruba correctly.

Where the script says `[pause]`, hold about three seconds. That is where the learner tries to answer before hearing the model.

After every learner answer, the teacher repeats the correct Yoruba answer. This is intentional. The learner needs to hear the correct target again immediately.

## What I Need From You

For each lesson, please answer the rater questions at the end of that lesson.

Please especially flag:

- Any Yoruba that is grammatically wrong.
- Any sentence that is technically correct but unnatural.
- Any tone mark that would make you say the wrong word.
- Any register issue, especially familiar vs respectful forms.
- Any teacher explanation that would confuse a beginner.
- Any place where a better everyday Yoruba phrase should replace the draft.

Honest criticism is much more useful than polite approval.
